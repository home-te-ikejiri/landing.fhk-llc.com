# 珈琲えんがわ　サイトの予約機能

## カレンダー機能
サイトトップにカレンダー機能を配置する 
扱う情報は下記の通り
- 喫茶店の営業予定表示
- レンタルルームの営業予定と利用状況

1. 表示する内容は下記の通り 
- １ヶ月分のカレンダー（PCは７列の票形式、スマホは２列（日付列と内容列）の票形式）
- ステータス表示
  - 喫茶店、レンタルルーム共通
    - 未登録時「-」
    - 店休日「休」
  - 喫茶店
    - オープン「◯」
  - レンタルルーム
    - 空きなし「✕」
    - 空きあり「◯」
    - イベント有「（イベントタイトルを表示）」

2. レンタルルームの残数計算
- 席数（席数）をマスター登録出来る（デフォルト３とする）
- 予約が入ると人数分減算する
- 席がなくなると「空きなし」表示とする

3. レンタルルームについて
- 日ごとで１時間単位で空き数を管理出来るようにする
- トップのカレンダーでレンタルルーム「◯」の日にちを選択すると、詳細画面が表示され、利用可能な時間帯を表示する
　利用者はその時間を見て、合いている時間を予約することが出来る。
- 利用者は申込フォームで予約する
- 予約確定は管理画面から送信出来るようにする（予約確定、予約受け付け不可）
- 予約時には、時付、時間（連続する時間が選択出来るように）、占有／共有、利用目的、人数、メールアドレス、氏名、電話番号を入力して送信出来るようにする。
　利用目的とは、打ち合わせ、セミナー、イベント、席利用などを確認する（事前にテーブルの配置が関係するため）
　占有／共有はフロアを借り切るか、席のみ利用する（フロアとしては他人がいる可能性がある）を選択させる。
- 予約が入ると残席数を減算する
- 管理画面では予約履歴が参照できること
- 管理画面では予約のキャンセル／消去ができること
- 管理画面から予約を登録出来ること。入力する内容は、ユーザー側と同じとする


4. イベントについて
- 管理画面にイベント登録画面を用意する
  - イベントタイトル、開催日、時間、人数、概要、金額を登録可能とする。
- ユーザー側ではカレンダー上のタイトルを選択すると、イベント詳細画面を表示する
- イベント詳細画面にある、申し込むボタンを押すと申込フォームに遷移する
- 申込フォームにて参加人数、参加者名（最大参加人数の上限までフォームを追加可能とする）、代表者電話番号、通信欄
- 申込フォームで申し込むがあったら仮予約とする。
- 管理画面で管理者がメールを返信し正常に送信されたことを確認して確定とする。
- 予約が完了したら人数から参加者数分減算する
- 管理画面では予約履歴が参照できること
- 管理画面では予約のキャンセル／消去ができること
- 管理画面から予約を登録出来ること。入力する内容は、ユーザー側と同じとする

5. お問い合わせフォーム
- レンタルルームのキャンセルや変更、イベントのキャンセルや変更も含め、お問い合わせフォームから行えるようにする


9. いずれ対応
- クレジットカード決済が出来るような作りにしておく（現時点では対応しない）
- 会員登録機能（現時点では登録しないが、各フォームで入力されたユーザー情報はデータベースに登録する

## rental_room_time_slots（レンタルルーム時間枠管理）

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | NOT NULL | AUTO_INCREMENT | PK |
| date | DATE | NOT NULL | | 日付 |
| hour | TINYINT UNSIGNED | NOT NULL | | 時間（0〜23の整数） |
| is_blocked | TINYINT | NOT NULL | 0 | 0:制限なし 1:管理者都合で不可 |
| admin_memo | VARCHAR(255) | NULL | | 不可にした理由など |
| created_at | TIMESTAMP | NULL | | |
| updated_at | TIMESTAMP | NULL | | |

- UNIQUE KEY: `(date, hour)`
- レコードが存在しない時間帯は「制限なし」として扱う（必要な日時のみ登録する運用）
- 管理画面から日付・時間帯単位で `is_blocked` を ON/OFF できる
- カレンダー詳細画面（日付選択後の時間帯一覧）での表示ロジック（優先順位順）：
  1. `is_blocked = 1` → **✕**（管理者都合で不可）
  2. `events` で `start_time ≦ 該当時間 < end_time` の公開イベントが存在する → **✕**（イベント貸し切り）
  3. `rental_room_reservations` で当該日・時間帯に重複する予約の `num_people` 合計が `rental_room_settings.capacity` 以上 → **✕**（予約満席）
  4. それ以外 → **◯**（空きあり、残席数も表示可能）
- カレンダー月表示での判定：
  - 「空きあり（◯）」：その日のいずれかの時間帯が上記ロジックで◯と判定される場合
  - 「空きなし（✕）」：営業日だが全時間帯が✕の場合
  - 「イベント有（タイトル）」：公開中イベントがある場合はタイトルを表示（◯と併記あり）
  - **◯とイベントタイトルは同じ日に同時表示あり**（例：午前◯・午後イベント貸し切り）
